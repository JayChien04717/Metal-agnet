# TSRI e-beam: A12 marks (pending)

`A12mark_TSRI.gds` is TSRI's mark artwork: a 12 × 12 mm field on layer 0/0. These are still to be defined with TSRI:
- placement (per die or per field)
- polarity
- layer
- the bare-rectangle margin

There is no TSRI-bound delivery until this is settled. Rules:

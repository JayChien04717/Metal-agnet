# TSRI e-beam: A12 marks (pending)

`A12mark_TSRI.gds` is TSRI's mark artwork: a 12 × 12 mm field on layer 0/0. These are still to be defined with TSRI:
- placement (per die or per field)
- polarity
- layer
- the bare-rectangle margin

The geometry is reproduced by `TSRIA12Mark` in [pattern design/marker/tsri_a12_mark.py](../../../pattern%20design/marker/tsri_a12_mark.py) (checked by `code/general/check_marker_references.py`).

There is no TSRI-bound delivery until this is settled. Rules:
[skill/fabrication_output.md](../../../skill/fabrication_output.md#tsri-a12-marks-pending).

1. Charging energies (Q3D Maxwell matrix, run fxarray_fl15, resonators included)
-------------------------------------------------------------------------------------
                 Ec [GHz]     C_sigma [fF]    target Ec
FX1              1.322        14.65           1.3 GHz    (cpw10_6: 1.310)

Ec = e^2/2 * C~^-1[i,i],  C~ = M^-T C M^-1 (sum/difference coordinates of each FX pad pair)

-------------------------------------------------------------------------------------
2. Qubit-qubit couplings (Q3D, fxarray_fl15)      J = 4 e^2 C~^-1[i,j] / h
-------------------------------------------------------------------------------------
FX1 - TC   (J_1c)    140.0 MHz   (sign -)   (cpw10_6: 136.9)
FX2 - TC   (J_2c)    141.9 MHz   (sign +)   (cpw10_6: 138.9)
FX1 - FX2  (J_12)     16.5 MHz   (sign -, direct; cpw10_6: 16.1, 15 / 5.909 um CPW: 12.1)

These are charge-charge couplings per charge number (n_i n_j). Multiply by the
charge matrix elements of the transitions involved to get the effective coupling.

3. Qubit-resonator couplings (Q3D, fxarray_fl15, resonators rendered)
-------------------------------------------------------------------------------------
                 beta = Cc/C_sigma    g/2pi (per n)      g/2pi (transmon conv.)   target
FX1 - R_FX1      0.203                160.9 MHz          -                         150 MHz
FX2 - R_FX2      0.196                160.3 MHz          -                         150 MHz
TC  - R_TC       0.233                175.6 MHz          157.1 MHz                 150 MHz
(cpw10_6: 157.9 / 157.1 / 159.4 MHz)

hbar g = 2 e beta V_zpf,  V_zpf = w_r sqrt(hbar Z0 / pi)  (lambda/2, Z0 = 50.9 Ohm),
w_r = design frequency. Fluxonium g excludes the qubit matrix element (thesis A.17).
Transmon convention multiplies by (32 Ec/EJ)^(1/4) with EJ/Ec = 50 assumed (thesis A.21).

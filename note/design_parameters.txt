1. Charging energies (Q3D Maxwell matrix, run tc5_x120_cl250, resonators included)
-------------------------------------------------------------------------------------
                 Ec [GHz]     C_sigma [fF]    target Ec
FX1              1.303        14.86           1.3 GHz
FX2              1.307        14.83           1.3 GHz
TC (coupler)     0.201        96.44           0.2 GHz

Ec = e^2/2 * C~^-1[i,i],  C~ = M^-T C M^-1 (sum/difference coordinates of each FX pad pair)

-------------------------------------------------------------------------------------
2. Qubit-qubit couplings (Q3D, tc5_x120_cl250)      J = 4 e^2 C~^-1[i,j] / h
-------------------------------------------------------------------------------------
FX1 - TC   (J_1c)    136.4 MHz   (sign -)
FX2 - TC   (J_2c)    138.3 MHz   (sign +)
FX1 - FX2  (J_12)     12.1 MHz   (sign -, direct)

These are charge-charge couplings per charge number (n_i n_j). Multiply by the
charge matrix elements of the transitions involved to get the effective coupling.

-------------------------------------------------------------------------------------
3. Qubit-resonator couplings (Q3D, tc5_x120_cl250, resonators rendered)
-------------------------------------------------------------------------------------
                 beta = Cc/C_sigma    g/2pi (per n)      g/2pi (transmon conv.)   target
FX1 - R_FX1      0.203                150.9 MHz          -                         150 MHz
FX2 - R_FX2      0.195                149.9 MHz          -                         150 MHz
TC  - R_TC       0.236                167.3 MHz          149.7 MHz                 150 MHz

hbar g = 2 e beta V_zpf,  V_zpf = w_r sqrt(hbar Z0 / pi)  (lambda/2, Z0 = 45 Ohm),
w_r = design frequency. Fluxonium g excludes the qubit matrix element (thesis A.17).
Transmon convention multiplies by (32 Ec/EJ)^(1/4) with EJ/Ec = 50 assumed (thesis A.21).

 * HFSS eigenmode (17 passes, +-10 MHz), simulated at lengths 9.302 / 9.606 / 9.015 mm.
   The layout lengths were then scaled by f_HFSS/f_target to 9.286 / 9.647 / 9.000 mm,

   re-simulated. The qubits were detuned low in the HFSS runs; the dispersive pull

** Q3D of feedline + tees + resonators (12 passes, 0.2 %), C_1 = -C[res, feedline],
   Q_c = pi / (Z0 Zr (C_1 w)^2), kappa = f / Q_c, Z0 = Zr = 45 Ohm. Uncertainty ~ +-3 %.

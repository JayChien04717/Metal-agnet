# Design6_TXT r9 readout-only S21 and capacitances (2026-11-16/17)

Simulation geometry only. The model has the feedline, both Purcell filters, both readout resonators, the Cp couplers and the r9 hammers. It has **no qubits, couplers or claws**: each resonator ends in an open where its claw would be. The resonators therefore sit above their loaded frequencies, so these numbers are not the operating point of the fabricated chip.

## Pole fit (re-analysis, no EM rerun)

Run: `20261117_071244_readout_poles_91e6875b` (`results/resonator/20261117_071244_readout_poles_91e6875b/run.json`) (figure (`results/resonator/20261117_071244_readout_poles_91e6875b/pole_fit.png`)), entry point [`readout_poles.py`](../simulation/resonator/readout_poles.py).

- Method: four complex poles on a cubic background, fitted to S_wide.
- The narrow line was then refitted on the 25 kHz S_fine grid.
- J was inverted per channel, assuming:
  - one lossy Purcell mode;
  - real J;
  - zero intrinsic loss;
  - no cross-channel coupling.

| Channel | Purcell-like pole (GHz) | κ_p (MHz) | Readout-like pole (GHz) | κ_r (MHz) | Bare fp / fr (GHz) | J (MHz) |
|---|---|---|---|---|---|---|
| Q2 (target 6.80) | 6.90257 | 33.7 | 7.09865 | 0.422 | 6.9050 / 7.0962 | 21.7 (conditional) |
| Q1 (target 7.00) | 7.11256 | 37.6 | 7.27746 | unresolved | — | unresolved |

- **Pairing:** the lower pair is Q2 because its lines are 3.2 % longer (filter 3.94469 vs 3.82263 mm; targets 6.80 vs 7.00 GHz). Within each pair, broad = Purcell and narrow = readout by linewidth. Field plots were not checked.
- **Detuning:** each readout line sits 165–197 MHz above its Purcell filter. The cause is the claw compensation: `design6_layout.tune_lengths()` designs f_p = f_r *with* the claw and shortens every resonator by `CLAW_DL` = 0.100 mm for its ≈17 fF end load. Removing the claw while keeping that shortening raises f_r by ≈ f·ΔL/L ≈ 7.0 × 0.1 / 4.1 ≈ 170 MHz. Design4_Single_purcell-res's `PurcellResonator` has no claw and no such shortening, so its f_p ≈ f_r and S21 shows the hybridized 2J splitting instead. Because the modes are this far apart, J comes only from the dispersive linewidth κ_r ≈ J²κ_p/Δ², which makes it sensitive to any extra decay path.
- **Possible extra decay on Q2:** the Q2 readout line (7.0986 GHz) lies 14 MHz below the Q1 Purcell pole (7.1126 GHz), so leakage through Q1's filter could broaden it. In that case 21.7 MHz is an upper bound.
- **Q1 readout line:** it lies outside S_fine and appears only as a ≈0.3 dB S21 bump on the 1 MHz fast-sweep grid, so its width and J are unresolved. A fine sweep around 7.27–7.29 GHz is needed.
- **Superseded wide-grid fit:** the first pole-fit run `20261117_031032_readout_poles_8ae48c8f` (`results/resonator/20261117_031032_readout_poles_8ae48c8f/run.json`) inverted J from the wide grid alone (0.40 / 0.22 MHz). Its J is not usable because the narrow widths are unresolved there. The second run `20261117_031132_readout_poles_d1550b75` (`results/resonator/20261117_031132_readout_poles_d1550b75/run.json`) had the correct numbers but swapped Q1/Q2 labels; it is superseded by `91e6875b`.

- **Network:** a two-channel nodal TL network of the actual r9 readout. Both channels sit on one feed line (no C_in), with 50 Ω ports.

Interpretation and limits:
- **f_p ≠ f_r even with 0.1 mm restored:** with the new Cp, the new hammer and 200 um spacing, the model predicts the readout line 48 MHz *above* the filter. The r9 lengths were tuned with the old inputs and never re-tuned. Contributions of the individual changes are not separated.
- **Model J is not trusted:** model J (4.7–4.9 MHz) is ≈4× below the HFSS dispersive estimate (21.7 MHz for Q2). This follows the Design4_Single_purcell-res pattern, where this model type was −76 % on J without coupled lines.
- **Relative frequencies are more reliable:** in Design4_Single_purcell-res the same model type was 20–35 MHz low in absolute fp / fr, but the fp − fr error was only ≈8 MHz.
- **HFSS check:** the +0.1 mm HFSS run below does not confirm the +48 MHz; see the next section.
- **Retune targets use an old correction:** the model frequency targets use the Design4_Single_purcell-res `HFSS_CORR`, which is not re-derived for this model. For the fabricated chip, `CLAW_DL` must be subtracted from L_res again.
- **Invalid first run:** `20261117_072443_readout_model_ef539f64` is recorded as completed, but its pole search converged to spurious zeros (half-widths ≈ 11 GHz, "J" ≈ 400 MHz). Do not use it.
- **Failed debugging runs:** `072529_3b696a72`, `072636_9f51bb9c`, `072756_af0d36b7` and `073458_a3071d1e` are failed pole-extraction attempts (status failed) and contain no results.

Interpretation:
- **The modes now hybridize.** With 0.1 mm restored, the S21 shows the 2J-type splitting expected for f_p ≈ f_r, as in Design4_Single_purcell-res.
- **The geometry change behaves as expected:**
  - The filter is unchanged, and so is its bare fp: Q2 6.9050 → 6.9042 GHz.
  - The readout line moved by the expected f·ΔL/L ≈ −170 MHz: Q2 bare fr 7.0962 → 6.9286 GHz.
- **J:** 16.1 / 16.6 MHz. This J comes from a hybridized pair, so it is less sensitive to extra decay than the earlier dispersive Q2 estimate (21.7 MHz), which was therefore too high. The inversion still assumes one lossy mode, real J, zero intrinsic loss and no cross-channel coupling.
- **The circuit model is off by 24–41 MHz in fr − fp.**
  - Most of the error is in the model Purcell frequency: model fp is 38–44 MHz below HFSS, while model fr is only 3–14 MHz below.
  - This is worse than the ≈8 MHz relative error seen in Design4_Single_purcell-res.
  - Do not use the model's +0.028 / +0.030 mm alignment lengths.
- **Residual alignment from HFSS directly.** With f ∝ 1/L on the readout line only, ΔL_res ≈ L_res·(fr − fp)/fr:
  - Q1: +0.0039 mm.
  - Q2: +0.0150 mm.
  - This is first order and excludes the claw, so treat it as an estimate, not a validated length.
- **Unchanged open item:** both Purcell filters still sit ≈ 100 MHz above the targets (7.114 vs 7.00 GHz, 6.904 vs 6.80 GHz).
- **Validation status:** unknown. Only one adaptive pass is below target, the data come from a fast-sweep interpolant, and field plots were not checked.

## Wallraff reference re-examined (re-analysis, no EM rerun)

Run: `20261117_115343_wallraff_check_adfc47c2` (`results/resonator/20261117_115343_wallraff_check_adfc47c2/run.json`), entry point [`wallraff_check.py`](../simulation/resonator/wallraff_check.py), shared formula [`code/general/purcell_j.py`](../../code/general/purcell_j.py). The old reproduction's output (git `2eb2bef`) is stored as an input snapshot.

| | Closed-form J | Full circuit | Table / HFSS J | Ratio |
|---|---|---|---|---|
| Wallraff Q32–Q36 | 15.1–16.2 MHz | 14.0–14.9 MHz | sim 15.0–15.8, meas 16.3–20.6 MHz | meas/sim 1.05–1.30 |
| Design6_TXT Q1 | 5.00 MHz | 4.91 MHz | HFSS 16.61 MHz | HFSS/closed form 3.32 |
| Design6_TXT Q2 | 4.80 MHz | 4.71 MHz | HFSS 16.10 MHz | HFSS/closed form 3.35 |

Findings:
- **The model itself is consistent.** The closed form reproduces Wallraff's J_sim, and Design6_TXT's `readout_model` agrees with the closed form. The model is therefore not the source of the low J.
- **Design6_TXT needs a coupling that the hammer does not supply.** HFSS needs an equivalent lumped C_j ≈ 2.2 fF, 3.3× the Q3D hammer. This is far above the Wallraff measured/sim spread (≤ 1.3).
  - Candidate paths: the ≈ 1.64 mm filter–resonator side-by-side run at 200 µm, which is anti-aligned in voltage, and ground return around the hammer.
  - Neither is quantified for Design6_TXT yet. Design4_Single_purcell-res's coupled-line model recovered part of the gap (−26 % on J remaining).
- **The old Wallraff reproduction validated J only.** Its ω_p − ω_r was 4.1–6.2× the table value and its κ_p was off by −55 % to +45 % per channel. The Design6_TXT circuit model's f_p error (−38 to −44 MHz versus HFSS) is of the same order. The lumped Cp / hugger end is the weak part of both models.
